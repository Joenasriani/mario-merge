# Mario Merge

**In-game title:** Mario Merge Upgraded  
**Status:** unofficial browser merge puzzle  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Mario Merge is a browser physics merge puzzle in which matching objects combine into progressively larger forms.

## Technology

HTML, JavaScript and Matter.js physics.

## Independence

This is an unofficial fan game project. It is not affiliated with or endorsed by Nintendo and is not an official Mario product.

Mario Merge and Mario Merge Upgraded refer to the same game lineage. Existing branches and historical files are retained as development history.
